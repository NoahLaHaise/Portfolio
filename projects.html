Zoom Transcript Summary Pipeline

An internal AI tool wired into the Zoom API through webhooks and REST endpoints that generates custom summaries of calls. Users trigger summaries on demand with their own prompts, or configure an automated pipeline for recurring meetings. Built for sales teams to surface insights from their calls, it includes a UI for managing, reviewing and regenerating summaries, plus a function-calling tool that lets an LLM pull summaries on demand.

I also built a retrieval-augmented generation layer on top, letting the marketing team query across every generated summary.
